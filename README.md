# Портфолио Даниила Бубнова

Статичный сайт без сборки: HTML + CSS + немного JS. Работает на GitHub Pages как есть.

## Структура

```
index.html              главная: кейсы
about.html              обо мне (из резюме)
risks.html              кейс «Оценка рисков»
kargo.html              кейс «Карго»
404.html
assets/css/style.css    все стили и цвета (переменные в :root)
assets/js/main.js       рамка выделения
assets/cases/<кейс>/    картинки кейсов
assets/cv.pdf           резюме для скачивания
```

## Публикация на GitHub Pages

1. Создайте репозиторий `ВАШ-ЛОГИН.github.io` — тогда сайт будет по адресу `https://ВАШ-ЛОГИН.github.io/`.
   (Можно и любое другое имя, но тогда адрес будет `…github.io/имя-репозитория/`
   и в 404.html придётся поправить пути.)
2. Загрузите все файлы в корень репозитория.
3. Settings → Pages → Source: *Deploy from a branch*, ветка `main`, папка `/ (root)`.
4. Через минуту сайт откроется. Свой домен подключается там же, в поле *Custom domain*.

## Как посмотреть сайт на компьютере

Распакуйте архив целиком и откройте `index.html` из распакованной папки.
Если открыть один html-файл отдельно от папки `assets`, стили и картинки не подгрузятся.

## Картинки

Сейчас картинки вырезаны из скриншотов страниц Figma Sites, поэтому они мягкие на ретина-экранах.
Замените их на экспорт из Figma/Pixso в 2x с теми же именами файлов — код менять не нужно.
Ширина 1600–2400 px, JPG или WebP, до 500 КБ на файл.

## Как выделяется элемент

Любому блоку можно добавить `data-select` — при наведении его обведёт синяя рамка
с размерами, как в Figma. `data-select-target=".artboard"` выделяет вложенный блок,
`data-select-start` — выделяет элемент при загрузке страницы.

## Английская версия

Весь текст лежит прямо в HTML, поэтому английская версия — это копия страниц в папке `en/`:

```
en/index.html
en/about.html
en/risks.html
en/kargo.html
```

1. Скопируйте страницы в `en/`, переведите текст, поставьте `<html lang="en">`.
2. Во всех путях к `assets/` добавьте один уровень `../`.
3. В шапке каждой страницы уберите атрибут `hidden` у ссылки `EN`,
   а в английских версиях сделайте ссылку `RU` на русскую страницу.
4. Раскомментируйте строки `hreflang` в `<head>` — так поисковики поймут, что это переводы.
